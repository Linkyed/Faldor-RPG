# Personagens não ficam Inconscientes
Agora quando reduzido a 0 pontos de vida, um personagem não fica mais Inconsciente, porem eles ficam em um estado de Morrendo, fazendo os mesmo caírem no chão e não conseguissem se levantar até que ganhem algum ponto de vida.
Durante esse estado de Morrendo um personagem pode realizar as seguintes ações durante o seu turno:

- Se arrastar (não pode usar nenhum tipo de ação para se levantar)
- Se comunicar
- Usar uma Ação, porem isso vai lhe dar 3 pontos de exaustão
- Usar uma Ação Bônus, porem isso vai lhe dar 1 ponto de exaustão
- Usar uma Reação, porem isso vai lhe dar 1 ponto de exaustão
